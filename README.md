# Simple Tasks

A simple full-stack task management application built with React and ASP.NET Core Web API.

## Screenshot

![Simple Tasks](screenshots/app.png)

## Features

- Create tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- RESTful API
- Docker support
- Basic API tests

---

## Tech Stack

### Frontend
- React
- Axios
- Tailwind CSS
- Vite

### Backend
- ASP.NET Core Web API
- C#

### Testing
- xUnit

### DevOps
- Docker
- Docker Compose
