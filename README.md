# Simple Tasks

Simple full-stack task management application built with React and ASP.NET Core Web API.

## Features

- Add tasks
- View tasks
- Delete tasks
- RESTful API
- Basic API tests
- Clean React frontend

## Stack

Frontend:
- React
- Axios
- TailwindCSS

Backend:
- ASP.NET Core Web API
- C#

Testing:
- xUnit

## Run Frontend

```bash
cd frontend
npm install
npm run dev

## Run Backend

```bash
cd backend
dotnet run

## Run Tests

```bash
cd tests
dotnet test
